Action state and solver budget

Bet targets are generated from this restricted tree. Earlier action likelihoods are not inferred; ranges must reflect the selected history. Turn search enumerates river cards and betting, so it is capped at four compatible private deals and 100 iterations. A target is checked against measured exact NashConv within this finite abstraction; best-response diagnostics add runtime and can exceed the time budget.
