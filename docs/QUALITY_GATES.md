# CPU quality gates before CUDA

These are forward-looking release criteria. A passing toy-game check does not substitute for a full Hold'em result.

| Gate | Evidence required | Current status |
|---|---|---|
| Hold'em rules | Deterministic rules, seeded conservation/legality tests, hidden-card isolation, independent hand-rank comparison | **Partial pass:** the full current suite passes 88 tests; 5,000 Treys comparisons agree. Exhaustive betting-tree verification remains. |
| Kuhn CFR | Exact NashConv < 0.01 after 10,000 iterations and value within 0.005 of −1/18 | **Pass:** 0.0046 NashConv, value −0.055546. |
| Leduc CFR | Exact NashConv < 0.2 after 500 synchronous iterations | **Pass:** 0.1395. |
| NFSP small-game learning | At least three seeded runs reduce exact NashConv; a later strength target is < 1.0 for all three seeds | **Learning pass, strength pending:** η=0.3 reduced all three by 20,000 episodes, but finals were 2.54–2.96. |
| Restricted Hold'em search | Exact best-response check in explicit ranges, agreement with engine action/payoff semantics, then validation on larger ranges and action-conditioned public histories | **Tiny postflop partial pass:** the shared river result matched the preserved reference exactly on one four-deal fixture; turn-to-river exact chance/betting runs and all-in payoff tests pass. River and turn ranges are still manually supplied, later actions are not likelihood-conditioned, and arbitrary real-game bet sizes can be unsupported. |
| Automatic live ranges | Fit action likelihoods on recorded play with known training hands; split by player/session; compare held-out log loss/calibration with context-only baselines; test posterior coverage and action-EV sensitivity | **Not met:** Bayesian event replay and blocker tests pass, but no fitted or held-out validated likelihood provider exists. Live solver feedback remains unavailable. |
| Earlier-street solver | Flop/turn/preflop betting and public chance traversal with blocker-correct ranges; compare conditional action EV and NashConv or tractable references on held-out states | **Partial mechanism, quality not met:** exact tiny-range turn→river CFR and flop→turn→river traversal exist. After exact rank/all-in caching, one-deal flop at 20 CFR+ iterations reached 0.102-chip restricted NashConv in 6.26 s. On three fixed four-deal turn boards, 100-iteration residuals were 0.0067–0.2104 chips and modal-action loss under 300-iteration profiles was at most 0.0408 chips, but one action-EV delta was 0.2345 chips and latency exceeded 5 seconds. Sampled runs were faster but more vulnerable. No preflop blueprint or broad-range validation exists; flop remains disabled in the app. |
| Neural continuation values | Held-out board/range split; value MAE ≤0.25 BB, RMSE ≤0.5 BB, mean action regret ≤0.125 BB and p95 ≤0.5 BB against deeper reference; faster end-to-end than shallow CPU solve | **Fail:** current model predicts root hand EV, not continuation values; MAE is 2.07–2.35 chips versus 0.96 for shallow CFR. No downstream action error has been measured. Gates are prospective and defined in `docs/PROJECT_METRICS.md`. |
| Hold'em agent strength | Multiple fixed opponents, seat rotation, enough hands for useful confidence intervals, no reliance on training reward alone | **Partial, strength fails:** three 10,000-hand self-play-trained 20-chip NFSP policies each played 1,000 fixed hands versus random and heuristic, with initialized-policy controls. Trained returns versus random were +0.86 to +1.48 chips/hand; versus heuristic −1.04 to −2.08. A faced-bet guard and a 30,000-hand seed-11 run did not improve measured return. Diagnose losses before claiming a strong agent. |
| CPU performance | Profile search and inference, record end-to-end latency and memory | **Partial:** a flop cProfile attributed most search time to repeated hand evaluation; exact rank/all-in caching reduced a one-deal flop run from 7.47 s to 2.26 s at one iteration with unchanged EV/NashConv. Bounded per-game caches pass a collection test. Larger-range process-memory profiles remain pending. |
| River range scaling | Measure traversal and memory beyond the nine-deal toy | **Partial:** 3/6/10 hands per seat measured with `tracemalloc`; 100 iterations took 1.47/5.37/13.80 s. Larger realistic ranges remain untested. |
| CUDA eligibility | All preceding gates pass on a stable CPU reference; compatible NVIDIA hardware available for numerical and end-to-end tests | **Locked:** preceding gates fail and this Apple M2 host has no NVIDIA CUDA GPU. |

The next useful cycles prioritize the shared solver: validate turn root action EVs and NashConv across independent boards/ranges, improve sampled chance quality or test a continuation approximation against exact tiny-game references, and fit/calibrate betting-history likelihoods before live advice. NFSP strength work remains separate and lower priority. Keep CUDA archived until the CPU gates are met.
